# v3.0.0 前端信息架构与视觉重构

> 历史迭代归档，不属于当前设计系统。当前设计规则见 [DESIGN.md](../../DESIGN.md)。

## 1. 决策

旧页面把自动化、JUnit、工作事项、项目、外部连接、运行任务和知识库放在两个混合工作台中，
导致“资产”“执行”“个人事项”“系统配置”混在同一页面。RAG 助手又放在顶部工具区，
无法形成稳定的全站上下文。

本次重构采用两项明确决定：

1. 交付与平台管理按职责拆页；
2. RAG 助手成为全站固定右侧栏，移动端在顶部栏右侧保留独立入口。

## 3. 右侧助手

- 桌面端：固定 46px 右栏，点击后打开 430px 抽屉。
- 移动端：顶部栏右侧独立按钮，打开全屏抽屉；不覆盖表单控件。
- 移动端项目身份位于顶部栏第二行，完整显示 Key、名称和角色。
- 助手不占主导航；页面不会因为切换路由而丢失入口。
- 当前事实、知识引用和模型推断分区展示。
- 无来源时拒答；知识文档与用户输入不能改变只读工具白名单。

## 4. 视觉系统

### Paper & Ink Workbench

- 纸本白 `#EFE8D6`：全站主画布，承载长时间阅读、表格和高密度操作。
- 钴蓝 `#1C4A9C`：左右栏、主操作、链接和信息状态。
- 猩红 `#DA2E2B`：当前位置、焦点、运行状态与风险强调。
- 4–6px 圆角、平面色块、1px 边线和紧凑间距。
- 浅色与深色均使用同一组语义令牌。

### 动效

- 路由：140ms、4px 上移淡入。
- 助手抽屉：240ms、横向进入。
- 导航选中：160ms 信号条。
- 解析与生成：单条工作状态扫描线。
- 尊重 `prefers-reduced-motion`。

## 5. 文案规则

- 页面不重复顶部标题。
- SectionCard 只显示标题，说明通过悬停获得。
- 字段说明默认收成 `?`。
- 空状态最多两行说明与一个主操作。
- 不在产品页面展示版本路线图、开发验收说明或“平台会如何”的流程宣言。
- 保留错误恢复、删除不可逆、权限、降级、来源和统计口径。

## 6. 使用的外部技能

- `impeccable`：Operate 模式、视觉方向、craft floor、机械 detector。
- `landing-page-design`：排版、间距、圆角、动效和文案约束。
- `ui-ux-pro-max`：数据密集型企业工作台检索、导航与表单建议。
- `deliver-acceptance-criteria`：页面职责与助手可用性的 Given/When/Then 验收标准。
- `playwright` / 现有冒烟脚本：真实浏览器桌面与移动端回归。
