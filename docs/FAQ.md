# 常见问题

## 启动与访问

### 没有大模型 API Key 能启动吗？

能。应用、文档解析、规则用例生成、指标计算、报告存档、项目治理和大部分导出不依赖模型。
模型相关能力会显式降级并返回原因。离线验证可使用：

```dotenv
LLM_PROVIDER=fake
```

### 浏览器打开出现 502 怎么办？

通常是本地代理拦截了 `127.0.0.1`。把 `127.0.0.1`、`localhost` 加入代理绕过列表，
或关闭系统代理后重试。访问地址应使用 `http://127.0.0.1:8000/`，不要使用 `0.0.0.0`。

### 端口被占用怎么办？

```powershell
python run.py --port 8123
```

### 为什么修改前端后界面没变化？

后端托管的是 `app/static/` 构建产物。执行：

```powershell
cd frontend
npm run build
```

然后刷新页面。

## 模型与 Prompt

### 所有工作流共用同一份模型配置吗？

是。`.env` 提供基线，界面运行时覆盖保存在本地配置中。优先级为：

```text
界面运行时覆盖 > .env > 代码默认值
```

报告阈值和图片识别配置独立，但图片识别可以复用模型 Key 与端点。

### 推荐使用哪个 DeepSeek 模型？

默认使用 `deepseek-flash`，成本较低。复杂结构化任务可通过路由策略选择更高质量模型。
思考型模型会先消耗推理 token，因此输出预算不能设置过小。

### 为什么模型温度有时不生效？

部分思考型模型在思考模式下不使用 `temperature`。配置页会根据厂商与模型能力显示提示。

### 模型下拉列表来自哪里？

来自后端模型目录和端点实时 `/models` 响应。新增厂商或模型应更新后端目录，不在前端硬编码。

### 如何接入其他 OpenAI 兼容服务？

选择 `openai_compatible`，填写保留 `/v1` 的兼容端点和 Key，保存后拉取模型列表。

### Prompt 如何避免把推断当事实？

每个模型任务使用独立 Prompt ID、输入边界和温度。证据会归一化校验，结论分为：

- `verified`：可被原文证据验证；
- `inferred`：只作为待复核模型判断；
- `rejected`：不进入权威需求、用例或指标。

### 为什么模型参与后仍然保留规则结果？

规则结果可复现、可离线核对。模型只负责复核、补缺或生成带来源标记的建议，不能静默覆盖规则产出。

## 文档与图片

### 支持哪些文件？

文档：DOCX、PDF、XLSX、TXT、MD、CSV、JSON。

图片：PNG、JPG/JPEG、WEBP、BMP、TIF/TIFF。

### 文档中的图片会解析吗？

会。`VISION_PROVIDER=auto` 按多模态模型、本地 OCR、云端 OCR 的顺序尝试。
主模型本身不需要支持图片。

### 如何让图片数据不出域？

使用：

```dotenv
VISION_PROVIDER=local-ocr
```

或者设置为 `none` 跳过图片识别。

### 图片识别失败会影响文档上传吗？

不会。文档仍可入库，每张失败图片会记录不可用原因和处理建议。

### 解析过的需求能回看吗？

能。文档详情中可查看结构化需求，原文也可以按原文件名下载。

### 重新解析会怎样？

重新解析会覆盖当前结构化需求，并可能再次消耗模型额度。仅在上传内容或解析策略确实变化时使用。

## 用例生成

### 六种设计方法能同时使用吗？

能。等价类、边界值、场景法、判定表、因果图和正交实验可以按次选择。

### 为什么设置了单条需求上限，最终条数还更少？

截断发生在去重之前。流程是：

1. 各方法生成候选；
2. 按方法轮转保留上限内的用例；
3. 再执行精确和跨方法语义去重。

所以最终条数通常少于截断上限。

### 上限应该设多少？

默认 `200`。复杂需求全方法生成时，几十条到上百条都可能出现。可在界面按次调整，
基线为 `MAX_CASES_PER_REQUIREMENT`。

### 大模型会改写规则用例吗？

默认不会。`review` 模式只产生复核意见；`enhance` 模式只追加带来源标记的新用例。

### 模型调用如何计预算？

复核按需求条目调用，不按设计方法次数调用。单次生成受 `LLM_MAX_CALLS_PER_GENERATION` 限制，
超出后保留规则结果并记录未复核条目。

### 用例集能追溯来源吗？

能。用例集记录来源需求、解析引擎、生成引擎、Prompt 元数据和降级信息；需求页也能反向列出用例集。

## 接口资产与自动化

### 支持 Swagger 2.0 吗？

不支持。当前只接受 OpenAPI 3.x 单文件 JSON/YAML。Swagger 2.0 和外部 `$ref` 会返回明确错误。

### Postman 导出会包含真实 Token 吗？

不会。导出使用 `{{baseUrl}}`、`{{authToken}}` 等环境占位符。

### 自动化资产会自动执行吗？

不会。zip 下载后在外部环境运行。平台提供另一条显式受控 HTTP 执行路径，只运行通过静态校验的
接口用例，不执行任意 Python 或 shell。

### 资产未通过安全门禁还能下载吗？

不能。资产记录会保留用于追溯，但下载返回 `409`。

### JUnit 中未匹配的 case 会丢失吗？

不会。运行详情分别展示匹配和未匹配结果，原始 `case_id` 会保留。

### 自动化 AI 会直接修改代码吗？

不会。建议先进入人工决定队列。采纳并显式应用后，才派生新的资产版本；原资产保持不变。

## 测试报告

### 指标是模型计算的吗？

不是。通过率、执行率、缺陷分布和发版判定由服务端确定性计算，模型只负责归纳和解释。

### 报告支持流式输出吗？

支持。`/report/analyze/stream` 使用 SSE 增量返回正文和进度。

### 如何修改发版判定阈值？

在报告设置页运行时修改，或配置 `VERDICT_*` 环境变量。界面可恢复 `.env` 基线。

### 执行记录能直接转成报告数据吗？

能。`/automation/runs/{run_id}/report-source` 返回报告工作台可使用的数据。

## 知识助手与联网

### 助手支持哪些问题？

支持测试概念、测试设计、缺陷分析、接口测试、自动化、代码生成/修改建议、项目状态、最近资源、
任务、新闻和一般技术问题。

### 为什么显示“联网可用”但某次没有联网？

联网只在问题需要实时信息或包含 URL 时触发，并受以下限制：

- 项目每分钟请求上限；
- 单会话联网次数；
- 两次联网最小间隔；
- 单次搜索结果数；
- 抓取网页数与正文长度。

达到限制时会使用已有上下文回答，并说明未联网原因。

### 如何启用其他模型的联网能力？

第三方模型必须提供兼容的 Search/Fetch JSON 契约，并配置：

```dotenv
ASSISTANT_WEB_SEARCH_BASE_URL=
ASSISTANT_WEB_SEARCH_API_KEY=
```

平台不会猜测厂商私有接口。

### 为什么回答状态显示“已回答”但仍有警告？

警告包含安全提示、引用范围、未实时探测链接、知识相关度等信息。只有真实调用失败、工具不可用、
空回答、无效引用等才标记“已降级”。

### 网页内容会改变系统指令吗？

不会。网页正文放在明确的不可信数据区，不能改变 Prompt 策略、工具白名单或输出契约。

### 助手能执行代码或修改项目文件吗？

不能。它可以生成代码、补丁和操作步骤，但不会在服务器执行，也不会修改平台资产。

### 会话记录保存在哪里？

保存在当前项目的助手会话存储中，并受项目边界校验。服务端限制会话轮次和上下文大小。

## 数据、备份与安全

### 数据存在哪里？

默认在 `storage/`：

- `uploads/`：上传原文和图片；
- `data/`：解析结果、用例、运行时配置和报告库；
- `exports/`：导出归档；
- `projects/<project_id>/`：项目隔离数据；
- `audit/`：审计事件。

备份整个 `storage/` 即可覆盖默认存储。

### 如何在 JSON 和 SQLite 之间切换？

先迁移：

```powershell
python scripts/migrate_json_to_sqlite.py
```

再设置：

```dotenv
STORAGE_BACKEND=sqlite
```

确认新后端可用前不要删除原 JSON 备份。

### 工作事项会进入 AI 或知识库吗？

不会。工作事项正文默认不进入 AI、RAG 或 Agent 上下文。

### 页面关闭后还会提醒吗？

不保证。提醒依赖页面打开时轮询；浏览器系统通知还需要显式授权。

### 对外部署前必须做什么？

- 开启 `AUTH_ENABLED`；
- 配置 `AUTH_TOKENS`；
- 收紧 CORS；
- 使用 HTTPS 和反向代理；
- 评估发送给第三方模型的数据范围；
- 设置存储备份与保留周期。

更多安全边界见 [安全策略](../SECURITY.md)。
