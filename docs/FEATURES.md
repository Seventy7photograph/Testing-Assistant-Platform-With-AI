# 功能总览

本文只描述平台当前已实现的能力、输入输出与操作边界。历史版本变化见
[`CHANGELOG.md`](../CHANGELOG.md)。

## 工作区

- 统一总览展示文档、结构化需求、用例集、用例总数、测试报告、自动化资产、执行记录与待跟进事项。
- 顶部栏提供项目切换、全局搜索、命令面板、密度切换、主题切换和帮助入口。
- 左侧主导航按工作域分组；右侧助手栏在全部页面可用，移动端使用独立入口和全屏抽屉。
- 支持标准、紧凑、宽松三档显示密度，以及纸本白浅色和钴蓝深色主题。
- 文档、用例集和报告存档支持批量删除；服务端限制单次请求最多 200 条并自动去重。
- 统一异常响应为 `{success, code, message, detail}`，成功响应为
  `{success, code, message, data}`。

## 需求与用例

### 文档输入

| 类型 | 支持范围 |
| --- | --- |
| 文档 | `.docx`、`.pdf`、`.xlsx`、`.txt`、`.md`、`.csv`、`.json` |
| 图片 | `.png`、`.jpg`、`.jpeg`、`.webp`、`.bmp`、`.tif`、`.tiff` |
| 直接输入 | 粘贴需求文本，作为可追溯文本文档入库 |
| 编码 | UTF-8、GB18030、GBK 等常见中文编码 |

上传的原文和解析结果分别保存。文档删除会同时清理原文、解析结果和关联知识索引。

### 图片识别

图片识别是独立通道，不要求主模型支持图片：

1. 多模态模型；
2. 本地 OCR，支持 RapidOCR、pytesseract 或 tesseract 命令；
3. 显式配置的云端 OCR。

`VISION_PROVIDER=auto` 时按上述顺序降级。识别文字回填到原文图片位置；图片描述作为独立推断段，
不参与字段约束抽取。通道不可用时文档仍可入库，并为每张图片记录原因和下一步。

### 结构化需求

- 大模型结构化抽取与规则解析双路运行。
- 模型不可用、输出不合法或证据校验失败时，显式降级到规则解析。
- 字段、业务规则、前置条件、主流程、备选流程、异常场景和验收标准进入统一需求模型。
- 证据闸门对原文引用做归一化核对，结论分为 `verified`、`inferred`、`rejected`。
- 需求条目与用例支持双向追溯、变更差异和覆盖率分析。

### 测试设计

当前支持六种设计方法：

| 方法 | 产出 |
| --- | --- |
| 等价类划分 | 有效类与无效类代表数据 |
| 边界值分析 | `min-1 / min / min+1 / max-1 / max / max+1` 等边界点 |
| 场景法 | 主流程、备选流程、异常流程和业务规则场景 |
| 判定表 | 条件桩、动作桩、规则展开与无关项合并 |
| 因果图 | 因、果、异或、包含、屏蔽约束，转换为规则用例 |
| 正交实验 | 因子与水平组合，生成两两覆盖用例 |

生成结果会去重、排序并按方法编号：`TC-EQ`、`TC-BV`、`TC-SC`、`TC-DT`、`TC-CE`、`TC-OR`。

### 大模型参与方式

- `scenario`：仅场景法补充易漏场景。
- `review`：六种方法的规则产出都可被只读复核，模型只提意见，不改写规则用例。
- `enhance`：在复核之外允许补充用例，新增项带来源标记，需人工复核。

复核按需求条目调用，受 `LLM_MAX_CALLS_PER_GENERATION` 限制。超出预算时保留规则结果并记录告警。

### 分析与追溯

- 字段、边界、规则三维覆盖率与缺口清单。
- 需求条目到用例、用例到需求的追溯矩阵。
- 新旧需求字段级差异对比。
- 同一需求的多次生成按版本保存。
- 用例集记录来源需求、解析引擎、生成引擎、Prompt 版本与降级原因。

### 导出

- Excel：用例明细、统计、需求追溯、生成信息。
- JSON。
- CSV。
- XMind。
- TestLink XML。

## 接口资产

- 导入 OpenAPI 3 JSON/YAML 单文件。
- 展开本地 `$ref`，保留循环引用占位并记录告警。
- 按 operation 生成正向、必填缺失、类型、枚举、长度、数值边界、Content-Type、鉴权与响应
  schema 断言。
- 无法从规范静态确定的断言标记为待人工补充，不编造约束。
- 响应示例仅用于展示，不作为固定返回值断言。
- 可选的大模型只读复核只保存建议，不修改路径、参数、schema 或既有断言。
- Postman Collection 2.1 保留 `{{baseUrl}}`、`{{authToken}}` 等占位符，不写入真实 Token。

## 自动化交付

### 受控 pytest 资产

- 从接口规范和可选用例生成版本化 `pytest + httpx` zip。
- 固定模板输出 `pytest.ini`、环境变量示例、fixtures、参数化数据、状态码与 schema 断言。
- Python AST、语法编译、危险导入/调用扫描和疑似密钥扫描全部通过后才允许下载。
- 平台不自动运行下载项目，也不执行任意 Python、shell 或下载脚本。

### JUnit 回收

- 导入 pytest JUnit XML，解析 passed、failed、error、skipped、耗时和输出。
- 通过 `case_id` 或测试名 marker 映射来源用例。
- 未匹配结果保留在 `unmatched_cases`，不会静默丢弃。
- 运行记录保存来源资产、来源哈希、原始 XML 与结构化事件。

### 受控 HTTP 执行

- 只执行通过静态校验资产中的接口用例。
- 目标主机必须来自 OpenAPI `servers` 或本次显式 `base_url`。
- 强制超时、并发、用例数和响应体大小限制。
- 环境变量只在本次请求使用，不写入运行数据。

### 工作事项

- note/task 两种类型。
- Markdown 正文、状态、优先级、截止时间、提醒、标签、置顶和关联资源。
- 收件箱、今日、近期、逾期、完成和最近记录视图。
- 失败执行可一键创建带 `test_run` 关联的跟进事项。
- 页面打开时轮询到期提醒；`reminded_at` 在服务端幂等去重。
- 页面关闭后不承诺后台提醒。

## 受控 AI 建议

自动化域提供四类人工触发任务：

| 类型 | 输入 | 输出 |
| --- | --- | --- |
| `operation_gap` | operation 结构摘要、未覆盖清单、允许的来源引用 | 覆盖建议与候选用例 |
| `failure_assertion` | 失败摘要、已有断言、来源 case | 断言补充建议 |
| `fixture_recipe` | 脱敏请求结构、环境变量名、case_id | fixture 与测试数据配方 |
| `script_review` | 已通过安全校验的资产文件 | 只读审查意见 |

人工采纳后可派生新的 case、断言、配方文件或资产版本。原资产和源 case 不变；派生资产重新执行静态门禁。
脚本只读审查不会自动应用。

## 测试报告

- 支持粘贴 JSON、上传 JSON 或使用内置示例数据。
- 服务端计算用例总数、通过率、失败率、阻塞率、执行率、缺陷分布和模块维度。
- 发版阈值支持运行时配置和恢复默认值。
- 判定结果为可发布、有条件发布或不建议发布。
- 支持一次性 AI 归纳与 SSE 流式输出。
- 报告存档支持检索、趋势、对比和批量删除。
- 导出格式：Markdown、HTML、DOCX、JSON。
- 执行记录可作为报告数据源，把自动化链路和报告链路连接起来。

## 项目与治理

- `X-Project-ID` 选择项目分区。
- 项目模式隔离文档、需求、用例、接口资产、运行记录、报告、知识索引和审计。
- `AUTH_ENABLED=true` 时通过 `X-API-Key` 与 `AUTH_TOKENS` 绑定项目、角色与操作者。
- 项目配额覆盖文档、用例集和任务。
- 审计记录项目操作、鉴权拒绝、同步、任务、Agent 调用和工具调用。
- Jira 与禅道支持真实 REST 拉取、用例回写、状态回读和健康检查。
- 无外部实例时可使用 JSON fixture 完成离线验收。
- 模型路由按任务、质量、成本和策略选择模型，决策理由进入生成或运行元数据。
- 任务、事件时间线、AgentRun 和 ToolCall 均可按项目追溯。

## 知识助手

- 项目级 SQLite FTS5 索引覆盖文档、需求、用例、接口规范、报告和平台帮助。
- 中文使用字符二元组召回，返回来源、版本、定位、摘要和相关性。
- 持久多轮会话，支持测试概念、测试设计、缺陷分析、接口测试、新闻与代码生成/修改建议。
- 健康、最近资源、任务、今日和逾期事项使用确定性只读工具。
- DeepSeek 自动调用官方 `/v1/tools/search` 与 `/v1/tools/fetch`。
- 其他模型可通过兼容 Search/Fetch 端点和独立 Key 启用联网。
- 网页正文按不可信资料进入 Prompt；网页引用在回答底部折叠展示。
- 服务端限制请求频率、会话轮次、上下文大小、联网次数、抓取数量和正文长度。
- 代码块可直接复制；模型只生成代码建议，不执行代码或修改文件。

## 明确边界

以下能力当前不提供：

- 任意 Python、shell、下载脚本或用户代码执行。
- 自动调度执行器；当前只登记调度定义。
- 未经人工采纳就自动修改自动化资产。
- 未经显式配置就猜测第三方厂商私有联网接口。
- 外部 `$ref` 自动下载和 Swagger 2.0 转换。
- 在页面关闭后保证后台提醒。

未实现的扩展入口会返回明确错误或 `501`，不会静默伪装为成功。
