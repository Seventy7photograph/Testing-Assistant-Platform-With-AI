# 电商订单系统需求说明书（示例）

> 本文件用于演示「需求文档 → 测试用例」链路，内容覆盖字段约束表、行内约束、
> 主流程 / 备选流程 / 异常场景 / 业务规则 / 验收标准等典型写法。

## 1、用户注册

用户通过手机号完成注册，注册成功后自动登录。

| 字段名 | 类型 | 必填 | 取值范围 | 说明 |
| --- | --- | --- | --- | --- |
| 手机号 | 字符串 | 是 | 11位数字 | 登录账号，全局唯一 |
| 昵称 | 字符串 | 是 | 2-20位 | 不允许重复 |
| 验证码 | 字符串 | 是 | 6位数字 | 短信验证码，5 分钟内有效 |
| 邀请码 | 字符串 | 否 | 6-10位 | 可选，用于绑定邀请人 |

注册状态取值：待激活/已激活/已冻结

主流程：
1. 进入注册页
2. 填写手机号、昵称
3. 点击获取验证码并在 60 秒内输入
4. 勾选用户协议
5. 提交注册

备选流程：
- 手机号已注册时提示用户直接登录
- 邀请码无效时提示重新输入，允许跳过

异常场景：
- 短信通道异常，验证码下发失败
- 数据库写入失败，注册中断
- 用户协议未勾选

业务规则：
- 若同一手机号已注册，则不允许重复注册
- 同一个手机号 60 秒内只允许发送一条验证码
- 不允许昵称包含敏感词

前置条件：
- 系统正常运行
- 短信通道可用

验收标准：
- 注册成功后自动登录并跳转首页
- 重复注册被拦截且提示明确

## 2、订单创建

用户将商品加入购物车后提交订单。

| 字段名 | 类型 | 必填 | 取值范围 | 说明 |
| --- | --- | --- | --- | --- |
| 商品数量 | 整数 | 是 | 1-999 | 单次下单数量 |
| 订单金额 | 小数 | 是 | 0.01-50000 | 单笔订单金额上限 |
| 收货地址 | 字符串 | 是 | 5-100位 | 收货详细地址 |
| 优惠券编号 | 字符串 | 否 | 8位 | 可选 |

订单状态取值：待支付/已支付/已取消/已发货/已完成

主流程：
1. 选择商品并加入购物车
2. 确认收货地址
3. 选择优惠券
4. 提交订单
5. 跳转支付

异常场景：
- 商品库存不足
- 支付超时自动取消订单

业务规则：
- 若订单金额超过 50000，则不允许提交
- 库存不足时不允许下单

验收标准：
- 下单成功后生成待支付订单

## 3、订单查询

订单查询支持按下单时间、订单状态组合筛选。

- 查询页码：1~1000
- 每页条数：10-100

主流程：
1. 进入订单列表页
2. 选择时间范围与状态
3. 点击查询
4. 查看订单详情

异常场景：
- 查询时间范围超过 1 年

业务规则：
- 不允许普通用户查询他人订单

验收标准：
- 查询结果与筛选条件一致

## 4、用户登录

用户使用已注册手机号与验证码登录，支持记住登录状态。

| 字段名 | 类型 | 必填 | 取值范围 | 说明 |
| --- | --- | --- | --- | --- |
| 登录手机号 | 字符串 | 是 | 11位数字 | 已注册的手机号 |
| 登录验证码 | 字符串 | 是 | 6位数字 | 短信验证码，5 分钟内有效 |
| 记住登录 | 布尔 | 否 | true/false | 勾选后 7 天内免登录 |

登录方式取值：验证码登录/密码登录

主流程：
1. 进入登录页
2. 输入手机号并获取验证码
3. 勾选记住登录
4. 提交登录
5. 跳转首页

备选流程：
- 未注册手机号提示先注册
- 验证码错误时允许重新获取

异常场景：
- 连续 5 次验证码错误锁定账号 10 分钟
- 账号已被冻结时拒绝登录

业务规则：
- 若账号被冻结，则不允许登录
- 同一手机号 60 秒内只允许发送一条验证码

验收标准：
- 登录成功后跳转首页并生效记住登录

## 5、退款申请

用户对已支付订单发起退款申请，按订单金额与状态走不同审批链路。

| 字段名 | 类型 | 必填 | 取值范围 | 说明 |
| --- | --- | --- | --- | --- |
| 订单编号 | 字符串 | 是 | 12位数字 | 已支付订单编号 |
| 退款金额 | 小数 | 是 | 0.01-50000 | 不得超过订单实付金额 |
| 退款原因 | 字符串 | 是 | 长度5~200 | 退款说明 |
| 凭证图片 | 字符串 | 否 | 不超过 5 张 | 最多 5 个附件 |

退款状态取值：待审核/审核通过/审核拒绝/退款中/已退款

主流程：
1. 进入订单详情页
2. 点击申请退款
3. 填写退款金额与原因
4. 上传凭证并提交

异常场景：
- 退款金额超过实付金额
- 订单未支付时不允许退款

业务规则：
- 若退款金额大于 50000，则必须走人工审核
- 已退款订单不允许重复申请

验收标准：
- 提交后退款单进入待审核状态
