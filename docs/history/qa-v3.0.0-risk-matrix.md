## 关键失败模式

### 项目边界失效

- 入口检查：请求头或 API Key 只通过一次解析。
- 存储检查：项目仓储使用独立根目录或数据库。
- 查询检查：知识、任务、审计 SQL 均带项目条件。
- 输出检查：响应不包含其他项目的引用、ID 或正文。

### 受控执行越界

- 资产必须 `validated`。
- 用例必须属于资产。
- URL 必须来自 OpenAPI `servers` 或本次 `base_url`。
- 禁止 URL 内嵌用户名/密码，禁止自动重定向。
- 读响应前检查累计字节。

### 知识引用失真

- 引用必须包含来源 ID、版本、定位与片段。
- 当前状态不能由 RAG 回答。
- 无 active 来源时不拼凑答案。
- 注入内容不能转换工具意图。
