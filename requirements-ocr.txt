# ==== 可选：图片识别（多模态 OCR）的本地/云端引擎 ====
#
# 核心依赖里已经有 pillow（图片下采样与格式归一）。
# 本文件只补「把图里的字认出来」这件事 —— 不装也能跑，只是图片会被显式跳过并告警。
#
# 三选一（也可都不装，改用多模态模型或云端 OCR）：
#
#   1) RapidOCR：纯 pip 安装、CPU 推理、自带中英文模型，离线私有化场景首选
#      pip install -r requirements-ocr.txt
rapidocr-onnxruntime>=1.3.0
#
#   2) pytesseract：需要另外安装 tesseract 本体与中文语言包（chi_sim）
#      pip install pytesseract
#      （Windows 版 tesseract 安装后请把安装目录加入 PATH）
#
#   3) 直接用命令行的 tesseract（无需任何 python 包）：把 tesseract 加入 PATH 即可，
#      平台会自动探测。
#
# 扫描件 PDF 的整页渲染（把无文字层的页面渲染成图片再交给 OCR）：
pypdfium2>=4.30
#
# 说明：识别通道的选择与降级顺序见 app/vision/registry.py；
# 界面「设置 → 图片识别」会显示当前实际使用的通道与不可用原因。
